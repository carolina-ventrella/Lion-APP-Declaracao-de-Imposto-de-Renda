# Descrição para entrega

LION APP: projeto em Excel com VBA para organizar dados do titular, informes bancários e entradas por categoria. Inclui planilha demonstrativa com dados fictícios, totalização bancária, validações e rotinas para incorporar, substituir e remover PDFs. A documentação apresenta as telas, explica as macros e registra testes pendentes.
